# 다정한 건강수첩

가족 구성원별 건강정보와 건강 기록, 병원 방문·복약 일정을 관리하는 정적 웹앱입니다. 로그인이나 앱 서버 없이 동작하며 입력한 내용은 현재 브라우저의 `localStorage`에 저장됩니다.

## 실행 방법

별도의 설치나 빌드 과정은 필요하지 않습니다.

1. 프로젝트 폴더에서 터미널을 엽니다.
2. 아래 명령으로 정적 파일 서버를 실행합니다.

   ```bash
   python -m http.server 8000
   ```

   Windows에서 `python` 명령을 사용할 수 없다면 `py -m http.server 8000`을 시도할 수 있습니다.
3. 브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다.
4. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

`index.html`을 직접 열어도 사용할 수 있지만, 브라우저마다 `file://` 주소의 저장소 동작이 다를 수 있어 위와 같이 여는 것을 권장합니다. 실행에 사용하는 정적 파일 서버는 화면 파일만 제공하며 건강정보를 서버에 저장하지 않습니다.

## 기능

- 가족 구성원 등록 및 구성원별 건강정보 확인
- 구성원별 건강 기록 추가·조회·삭제
- 병원 방문 및 복약 일정 추가·조회·삭제
- 브라우저 `localStorage`를 이용한 자동 저장
- 모바일·태블릿·데스크톱 반응형 화면

## 저장 및 개인정보 안내

데이터는 사용 중인 브라우저와 웹 주소(`localhost` 등)에 연결된 로컬 저장 공간에 저장되며 기기 간 동기화되지 않습니다. 브라우저 저장 데이터를 지우면 기록도 삭제될 수 있으니 공용 기기에서 민감한 건강정보를 입력하지 않도록 주의해 주세요. 이 앱은 개인 건강관리용 기록 도구이며 의료진의 진단이나 응급 진료를 대신하지 않습니다.

## 파일 구성

- `index.html` — 앱 화면과 구성원 등록 창
- `styles.css` — 반응형 화면 스타일
- `app.js` — 화면 동작과 `localStorage` 데이터 관리

이 프로젝트는 외부 라이브러리나 빌드 도구를 사용하지 않습니다.
