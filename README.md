# 다정한 건강수첩

가족 구성원별 건강정보와 건강 기록, 병원 방문·복약 일정을 정리하는 개인용 웹앱입니다. **의료 진단·치료 앱이 아닙니다.** 로그인이나 앱 서버 없이 동작하며 입력한 내용은 현재 브라우저의 `localStorage`에 저장됩니다.

## 의료 이용 관련 안내

- 이 앱은 사용자가 입력한 건강정보를 보관·조회하기 위한 기록 도구이며, 증상이나 검사 결과를 분석하거나 질병을 진단하지 않습니다.
- 치료 방법이나 복약 여부·용량·시간을 권고하거나 의료인의 전문적 판단을 제공하지 않습니다. 앱에 적은 정보만으로 치료를 결정하거나 처방을 변경하지 마세요.
- 증상, 검사 결과 또는 약에 관한 판단은 의료진이나 약사와 상담하세요. 응급 상황에서는 앱을 이용하지 말고 **119 또는 현재 지역의 응급서비스**에 연락하세요.
- 기록의 정확성과 최신성은 입력한 내용에 따라 달라집니다. 의료진에게 보여줄 때는 원본 처방전·검사 결과 등과 함께 확인하세요.

## 단일 웹파일로 바로 열기

한 파일만으로 실행할 수 있도록 화면, 디자인, 기능을 담은 `다정한-건강수첩.html`이 있습니다.

1. `다정한-건강수첩.html` 파일을 더블클릭하거나 브라우저의 **파일 열기** 메뉴로 선택합니다.
2. 화면이 열리면 가족 구성원을 등록해 사용합니다.

별도 설치, 빌드, 웹 서버 또는 다른 프로젝트 파일은 필요하지 않습니다. 인터넷에 웹사이트를 게시하는 방식은 아니며 데이터는 사용 중인 브라우저의 `localStorage`에 저장됩니다. `file://` 주소의 저장 공간 동작은 브라우저 설정에 따라 다를 수 있고, 다른 기기나 브라우저와 동기화되지 않습니다. 저장 상태 표시가 경고로 바뀌면 해당 브라우저에서 저장이 제한된 것일 수 있습니다. 인터넷 주소로 공개하려면 별도의 웹 호스팅이 필요하고, 여러 기기에서 데이터를 공유하려면 서버와 데이터베이스가 추가로 필요합니다.

## 기존 프로젝트 파일로 열기

기존 분리형 앱으로 사용하려면 `index.html`을 더블클릭하거나 브라우저의 **파일 열기** 메뉴로 선택합니다. 화면과 기능을 불러올 수 있도록 `index.html`, `styles.css`, `app.js`를 같은 프로젝트 폴더에 함께 두세요. `index.html`만 따로 옮기면 스타일과 기능 파일을 찾지 못할 수 있습니다.

## 기능

- 가족 구성원 등록·수정·삭제 및 구성원별 건강정보 확인
- 구성원 이름의 공백·유니코드 표기를 정리해 중복 등록 방지(수정할 때는 본인 이름 유지 가능)
- 이름을 비우거나 공백만 입력한 경우 등록·수정 차단 및 안내
- 구성원별 건강 기록 추가·조회·삭제
- 병원 방문 및 복약 일정 추가·조회·삭제
- 삭제 확인 창에서 취소하면 데이터와 연결 정보 유지
- 브라우저 `localStorage`를 이용한 자동 저장
- 모바일·태블릿·데스크톱 반응형 화면
- 모바일에서 가족 목록과 건강정보를 한 열로 배치하고 주요 버튼·삭제 영역의 터치 공간 확대
- 모바일 입력 글자 크기와 기록 제목·메모의 가독성 개선
- 분리형 앱 첫 화면에 의료 진단·치료 앱이 아니라는 안내와 의료·응급서비스 안내 표시
- 단일 웹파일 하단에 기록 도구가 의료진의 진단·응급 진료를 대신하지 않는다는 안내 표시

가족 구성원을 삭제하면 해당 구성원에게 연결된 건강 기록과 병원·복약 일정도 함께 삭제됩니다. 삭제 전에 확인 창에 연결된 항목 수가 표시되며, 삭제 후에는 되돌릴 수 없습니다.

## 의료 안내 문구 확인

`index.html`을 열어 환영 영역 바로 아래에 **“의료 진단·치료 앱이 아닙니다”** 안내가 표시되는지 확인합니다. 안내에는 앱이 증상 진단이나 치료·복약 지시를 제공하지 않는다는 점, 의료진·약사 안내를 따를 것, 응급 상황에는 119 또는 현지 응급서비스에 연락할 것이 포함됩니다. 페이지 하단에도 기록 도구의 한계가 다시 표시됩니다.

`다정한-건강수첩.html` 단일 파일에도 페이지 하단에 개인 건강관리용 기록 도구이며 의료진의 진단이나 응급 진료를 대신하지 않는다는 문구가 있습니다. 이 단일 파일은 첫 화면의 별도 의료 안내 배너를 제공하지 않습니다.

## 모바일 화면 수동 점검

아래 절차는 실제 휴대전화 또는 브라우저 개발자 도구의 반응형 모드에서 확인할 수 있습니다. 실제 브라우저 실행·시각 검증은 제공된 파일 도구만으로 수행할 수 없어 아직 완료하지 않았습니다.

1. `다정한-건강수첩.html` 또는 `index.html`을 엽니다. 반응형 모드에서는 너비 **320px, 375px, 390px, 430px**를 차례로 확인합니다.
2. 가족 구성원이 두 명 이상 보이도록 테스트 구성원을 추가합니다. 이름·관계·나이가 잘리지 않고 각 구성원을 터치해 선택할 수 있는지, 작은 화면에서 가족 목록이 한 열로 표시되는지 살펴봅니다.
3. 구성원 상세 화면에서 수정·삭제 버튼, **기록 추가**, **일정 추가** 버튼을 손가락으로 누르기 쉬운지 확인합니다. 기록/일정 카드가 모바일에서 한 열로 쌓이고 페이지 가로 스크롤이 생기지 않는지도 확인합니다.
4. 건강 기록 추가 폼을 열어 종류·날짜·제목·메모 입력란과 저장·취소 버튼이 화면 폭 안에 들어오는지 확인합니다. 입력란의 글자가 작지 않은지, 저장한 기록의 날짜·제목·메모 및 삭제 버튼이 서로 겹치지 않는지 확인합니다.
5. 구성원 정보 편집 창을 열고 작은 화면에서 모든 입력란과 하단 버튼까지 세로로 스크롤할 수 있는지 확인합니다.

## 입력 오류와 삭제 취소 수동 확인

아래 점검은 단일 파일(`다정한-건강수첩.html`) 또는 분리형 앱(`index.html`)을 열고 테스트용 정보를 사용해 진행하세요.

1. **빈 이름**: 구성원 등록 창을 열고 이름을 비운 채 등록을 눌러 봅니다. 브라우저의 필수 입력 안내와 앱 안내가 표시되고 구성원 수가 바뀌지 않아야 합니다. 이름에 공백만 입력한 경우도 등록되지 않아야 합니다.
2. **중복 등록**: `테스트 가족`을 한 번 등록한 뒤 같은 이름으로 다시 등록해 봅니다. 앞뒤 공백, 중간의 여러 공백, 전각 문자 차이만 있는 이름도 중복으로 처리됩니다. 중복 안내가 나타나고 창은 열린 채 유지되며 구성원 수가 늘지 않아야 합니다. 수정 창에서 해당 구성원 자신의 이름을 그대로 저장하는 것은 허용되고, 다른 구성원과 같은 이름으로 바꾸는 것은 차단되어야 합니다.
3. **삭제 취소**: 테스트 구성원에게 건강 기록이나 일정을 추가한 뒤 삭제 아이콘을 누릅니다. 확인 창에서 **취소**를 선택하면 구성원과 연결된 기록·일정, 화면의 수가 그대로 유지되어야 합니다. 새로고침 뒤에도 데이터가 남아 있는지 확인합니다. 확인 창을 사용할 수 없는 환경에서는 삭제가 진행되지 않도록 처리했습니다.
4. **삭제 확정**: 다시 삭제 아이콘을 누르고 확인 창에서 확정합니다. 구성원과 연결 정보가 사라지는지 확인합니다. 마지막 구성원을 삭제했다면 빈 화면과 구성원 수 `0명`이 표시되어야 하며, 새로고침 뒤에도 삭제 상태가 유지되어야 합니다.

## 구성원 등록·수정·삭제 및 저장 확인 방법

아래 순서로 등록 → 수정 → 삭제 → 새로고침 동작과 브라우저 저장을 확인할 수 있습니다. 실제 가족의 민감한 건강정보 대신 테스트용 이름과 정보를 사용하세요.

1. **등록**을 눌러 테스트 구성원(예: `테스트 가족`)을 등록합니다. 이름이 가족 목록과 건강정보 화면에 표시되는지 확인합니다.
2. 구성원 건강정보 화면에서 **수정**을 누릅니다. 이름이나 관계를 바꾸고 **변경사항 저장**을 선택합니다. 목록과 상세 화면에 수정한 내용이 반영되는지 확인합니다.
3. 같은 화면의 삭제 아이콘을 누르고 확인 창에서 구성원 삭제를 확정합니다. 구성원이 목록에서 사라지고, 마지막 구성원을 삭제했다면 빈 화면과 구성원 수 `0명`이 표시되는지 확인합니다. 건강 기록이나 일정이 연결되어 있다면 해당 데이터도 함께 삭제된다는 안내를 확인합니다.
4. 브라우저에서 새로고침(Windows/Linux: `Ctrl+R`, macOS: `⌘R`)합니다. 삭제한 구성원이 다시 나타나지 않는지 확인합니다. 남은 가족이 있다면 그 구성원은 계속 표시되어야 합니다.

삭제 확인 창에서 취소한 데이터의 새로고침 후 유지 여부를 점검하려면, 삭제를 취소한 직후 새로고침하거나 별도의 테스트 구성원을 사용하세요. 저장 상태 표시가 **이 기기에 저장**인지도 확인해 주세요. 앱은 현재 브라우저의 `localStorage`에 저장하므로 다른 브라우저·기기와 동기화되지는 않습니다.

위 절차는 수동 확인 방법입니다. 실제 브라우저 실행 및 클릭 테스트는 제공된 파일 도구만으로 수행할 수 없어 아직 실행하지 않았습니다. 사용 중인 브라우저에서 직접 확인해 주세요.

## 저장 및 개인정보 안내

데이터는 사용 중인 브라우저의 로컬 저장 공간에 보관되며 기기 간 동기화되지 않습니다. 이 방식은 서버 백업이나 접근 제어를 제공하지 않으며, 저장 데이터가 암호화된다는 보장도 없습니다. 브라우저 저장 데이터를 지우면 기록도 삭제될 수 있으니 공용 기기에서 민감한 건강정보를 입력하지 않도록 주의해 주세요. 가족 구성원의 동의를 얻고, 필요한 최소한의 정보만 기록하는 것을 권합니다.

이 앱은 개인 건강기록·일정 정리 도구입니다. 진단·치료·복약 판단에는 의료진이나 약사의 안내를 이용하고, 응급 상황에는 119 또는 현지 응급서비스를 이용하세요.

## 파일 구성

- `다정한-건강수첩.html` — CSS와 JavaScript를 포함한 단일 실행 웹파일
- `index.html` — 기존 분리형 앱 화면과 의료 안내
- `styles.css` — 기존 분리형 앱의 반응형 화면 스타일
- `app.js` — 기존 분리형 앱의 화면 동작과 `localStorage` 데이터 관리
- `README.md` — 실행, 기능, 수동 확인, 의료·개인정보 안내

이 프로젝트는 외부 라이브러리나 빌드 도구를 사용하지 않습니다.
